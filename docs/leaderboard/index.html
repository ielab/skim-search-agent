Metrics

What each column means

Accuracy

The share of all 830 questions the Qwen3-32B judge marks correct, with the BrowseComp-Plus judge prompt. An answer the judge gives no verdict on counts as wrong.

Recall

For each question, the share of its evidence documents (gold and evidence together) that any search result showed the agent, averaged over all 830 questions.

Search calls

The mean number of search calls per question.

Tokens

The mean tokens per question, each token counted once: the largest prompt the episode held plus every token the model generated. It is not the sum of the prompts over the turns.

Rank

Rows rank by accuracy inside the view shown. Click a column header to sort by it instead.

All

Every row. The menus under Agent, Retriever and Reranker choose which agents, retrievers and rerankers the table includes.

Retrievers

One part varies: the retriever. The agent is Tongyi-DeepResearch-30B-A3B and there is no reranker.

Rerankers

One part varies: the reranker. The agent is Tongyi-DeepResearch-30B-A3B and the retriever is Qwen3-Embedding-0.6B. Rerankers over other retrievers are in All.

Agent backbones

One part varies: the agent model. The retriever is Qwen3-Embedding-0.6B and there is no reranker. Agents run with other retrievers are in All.

Setting

What stays fixed

  • Agent: Tongyi-DeepResearch-30B-A3B served with vLLM, temperature 0.6, seed 42. A row with another agent model keeps everything else on this list and runs that model with its own prompt family, sampling settings and tool-call format.
  • Corpus: the original BrowseComp-Plus text, 100,195 documents, all 830 questions.
  • Tools: search returns the top 10 documents with a 64-token snippet each. get_document reads a document, cut at 12,000 tokens.
  • Budget: 100 turns and a 131,072-token context window.
  • Encoding: every learned retriever encodes a document's first 512 tokens.
  • Rerankers: each reorders the retriever's top 100. The agent sees the top 10.
  • Base retriever: the Rerankers and Agent backbones views fix the retriever to Qwen3-Embedding-0.6B, so their rows differ in one part only.
  • Lists of queries: when the agent sends several queries in one call, the first one runs.
Run a row

Every row is one file

A row's file is configs/baselines/browsecomp_plus_<row>_tongyi.yaml. A backbone row's file is configs/baselines/browsecomp_plus_<retriever>_<backbone>.yaml. Build its index, serve the agent model, run the file and judge the answers. docs/BASELINES.md has every step and command.

skimsearchagent run configs/baselines/browsecomp_plus_colbert_tongyi.yaml \
  model.backend=api model.api_base=http://127.0.0.1:8000/v1
# after the three judges: the row's accuracy, recall and search calls
python scripts/leaderboard_row.py <the run's results directory>
