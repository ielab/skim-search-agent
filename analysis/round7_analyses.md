# Job 2 — cross-backbone replication check (PRELIMINARY — run still filling)

`analysis/xbackbone_analysis.py` is written to be re-run repeatedly as `runs/_xbackbone` fills,
reading both the canonical merged `rows.jsonl` and any not-yet-merged `__shards/.../rows.jsonl`
files, deduping by `instance_id`. It refuses to over-claim on partial data: it prints a prominent
`PARTIAL RUN WARNING` and labels every number "preliminary, n=X of 830, not for publication"
whenever either condition is below 90% completion, and refuses to compute a significance test
below 200 shared (paired) instances (prints "insufficient" instead).
